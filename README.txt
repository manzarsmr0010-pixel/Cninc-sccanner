CNIC Scanner
============

A single-file browser app for detecting, straightening and cropping Pakistani CNIC photos.

Files:
- index.html — complete application

Hosting:
- GitHub Pages: upload index.html to a repository and enable Pages.
- Netlify: deploy the folder containing index.html.

Privacy:
- Images are processed locally in the browser. There is no server or image upload.

Usage:
1. Open index.html.
2. Upload/capture Front and/or Back.
3. Adjust the four green corner handles if necessary.
4. Download individual JPGs or load both sides and download the A4 JPG.
